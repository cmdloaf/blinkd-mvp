ID: consistent_mental_model
Category: Usability
Description:
The product's structure, terminology, and behavior align with how users think about the task. Labels use user language rather than internal jargon. Navigation follows intuitive groupings based on user goals. Actions produce predictable results that match what the interface implies.

Prevents:
- Mental model mismatch
- Users looking for features in wrong places
- Label confusion and misinterpretation
- Unnecessary learning curve

Outcome:
Users navigate confidently because the product works the way they expect. Reduced support requests and faster task completion. Users feel the product was designed for them.
