ID: onboarding_failure
Category: Onboarding

Bad UX Pattern:
New users are dropped into the product without adequate guidance on what it does, how to start, or what value they will get. The onboarding flow either does not exist, is too long and complex, or fails to connect product features to user goals.

Symptoms:
- New users stare at the screen unsure what to do first
- Users click randomly trying to understand the interface
- Users leave within the first session without completing key actions
- Users misunderstand the product's purpose
- High churn within first 24 hours

User Impact:
Failed activation and early abandonment. Users never reach the product's value proposition and form a negative first impression that prevents return visits.

Good UX Principle:
New users are introduced through a structured, goal-oriented sequence that connects features to user value. The onboarding flow shows what the product does, helps users complete a meaningful first action, and builds confidence through early wins.

Actionable Correction:
Create a structured onboarding sequence focused on first meaningful action. Connect features to user goals. Provide contextual guidance that disappears once the user demonstrates competence. Minimize time to first value.
