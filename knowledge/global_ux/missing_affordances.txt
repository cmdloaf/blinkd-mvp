ID: missing_affordances
Category: Interaction Design

Bad UX Pattern:
Interactive elements do not visually communicate that they are clickable, tappable, or otherwise actionable. Links look like plain text, buttons look like decorative elements, draggable items have no drag handles, and expandable sections have no expand indicators.

Symptoms:
- Users do not realize elements are clickable
- Users hover or tap randomly trying to discover functionality
- Users miss key features because the entry point is not visually distinct
- Users report that features are "missing" when they are actually present but hidden
- Low engagement with important interactive elements

User Impact:
Feature discovery failure and underutilization. Users complete tasks using longer paths because they cannot identify the direct interaction. Products appear less capable than they are.

Good UX Principle:
Interactive elements clearly communicate their actionable nature through visual design. Buttons look like buttons, links are visually distinct from text, draggable items have drag handles, and expandable sections have clear indicators.

Actionable Correction:
Make all interactive elements visually distinct from static content. Use established visual conventions for buttons, links, and controls. Add hover states, cursor changes, and visual affordance cues.
